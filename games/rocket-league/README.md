# Rocket League Multiplayer Prototype

A browser-based multiplayer car-soccer game inspired by Rocket League.

## Features
- 3D arena with cars and ball
- Boost system
- Real-time multiplayer via Photon
- Username + optional password (stored locally)
- Basic local leaderboard
- Quick Match / Private rooms

## Controls
- **W / ↑** – Accelerate
- **S / ↓** – Brake / Reverse
- **A / ←** – Steer left
- **D / →** – Steer right
- **Shift** – Boost

## Important Notes
This is a **prototype**, not a full accurate Rocket League clone.

Full realistic physics, aerial control, online ranked, secure global accounts, and a true worldwide leaderboard would require:
- Much more advanced physics (custom engine or library)
- Dedicated server or more complete Photon setup
- A real backend for accounts & leaderboards (Firebase / Supabase / etc.)

You can improve this base over time.

## How to play
1. Open the game from the Game Hub
2. Enter a username
3. Click Quick Match or create a private room
4. Share the room name with friends if private
