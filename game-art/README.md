# Game Art

Each game has its own folder with artwork used by the main hub:

| File | Use |
|------|-----|
| `profile.svg` | Square icon on the game card |
| `banner.svg` | Wide banner across the top of the card |
| `data.js` | Photo-style images embedded for the hub |

Folders match game names: `live-earth`, `storm-chaser`, `snake`, `slitherIO`, `cat-game`, `garticphone`, `royale`, `werewolf`, `heads`.

To replace art later: put `profile.png` and `banner.png` in the same folder (hub will prefer those if you wire them), or edit the SVGs.
